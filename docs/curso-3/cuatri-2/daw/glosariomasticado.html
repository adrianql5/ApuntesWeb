1. HTML

HTML sirve para definir la estructura de una página web.

1.1. Estructura básica del documento

Elemento Uso Ejemplo
<!DOCTYPE html> Indica que el documento usa HTML5. <!DOCTYPE html>
<html> Raíz del documento. <html>...</html>
<head> Contiene metadatos, título, CSS, scripts. <head>...</head>
<body> Contiene lo visible de la página. <body>...</body>
<meta> Define metadatos, como codificación. <meta charset="UTF-8">
<title> Título de la pestaña del navegador. <title>Mi página</title>
<link> Enlaza recursos externos, normalmente CSS. <link rel="stylesheet" href="style.css">
<script> Inserta o enlaza JavaScript. <script src="codigo.js"></script>
<style> CSS interno dentro del HTML. <style>p { color: red; }</style>

1.2. Texto y formato

Elemento Uso Ejemplo
<h1> a <h6> Encabezados, de mayor a menor importancia. <h1>Título</h1>
<p> Párrafo. <p>Texto</p>
<br> Salto de línea. Es elemento vacío. Hola<br>Adiós
<strong> Texto importante, normalmente en negrita. <strong>Importante</strong>
<b> Negrita visual, sin tanta carga semántica. <b>Texto</b>
<em> Énfasis semántico, normalmente cursiva. <em>Atención</em>
<i> Cursiva visual o término especial. <i>status quo</i>
<mark> Texto resaltado. <mark>clave</mark>
<blockquote> Cita larga. <blockquote>Texto citado</blockquote>
<q> Cita corta en línea. <q>Hola</q>
<pre> Texto preformateado, respeta espacios y saltos. <pre>línea 1\nlínea 2</pre>
<time> Fecha u hora semántica. <time datetime="2026-05-17">17 mayo</time>

Diferencia importante:

<b>negrita visual</b>
<strong>importancia semántica</strong>

<i>cursiva visual</i>
<em>énfasis semántico</em>

1.3. Contenedores y estructura semántica

Elemento Uso Ejemplo
<div> Contenedor genérico de bloque. <div class="caja">...</div>
<span> Contenedor genérico en línea. <span>texto</span>
<header> Cabecera de página o sección. <header>...</header>
<footer> Pie de página o sección. <footer>...</footer>
<main> Contenido principal. <main>...</main>
<section> Sección temática. <section>Noticias</section>
<article> Contenido independiente. <article>Post</article>
<aside> Contenido lateral o complementario. <aside>Publicidad</aside>
<nav> Zona de navegación. <nav><a href="#">Inicio</a></nav>

Idea rápida:

<div>

sirve para agrupar sin significado semántico especial.

<section>, <article>, <nav>, <main>

aportan significado a la estructura.

1.4. Listas

Elemento Uso Ejemplo
<ul> Lista desordenada. <ul><li>Uno</li></ul>
<ol> Lista ordenada. <ol><li>Uno</li></ol>
<li> Elemento de lista. <li>Elemento</li>
<dl> Lista de definición. <dl>...</dl>
<dt> Término. <dt>HTML</dt>
<dd> Definición. <dd>Lenguaje de marcado</dd>

Ejemplo:

<dl>
  <dt>HTML</dt>
  <dd>Lenguaje para estructurar páginas web.</dd>
</dl>

1.5. Enlaces e imágenes

Elemento Uso Ejemplo
<a> Enlace. <a href="pagina.html">Ir</a>
<img> Imagen. Elemento vacío. <img src="foto.jpg" alt="Foto">
<picture> Imágenes adaptativas. <picture>...</picture>
<source> Fuente alternativa para imagen, audio o video. <source src="video.mp4" type="video/mp4">
<iframe> Inserta otra página dentro. <iframe src="pagina.html"></iframe>

Ejemplo de imagen:

<img src="logo.png" alt="Logo de la empresa">

alt es importante porque ofrece texto alternativo si la imagen no carga o para accesibilidad.

1.6. Formularios

Elemento Uso Ejemplo
<form> Formulario. <form action="login" method="post">
<input> Campo de entrada. <input type="text" name="usuario">
<label> Etiqueta asociada a un campo. <label for="email">Email</label>
<textarea> Campo de texto largo. <textarea name="mensaje"></textarea>
<select> Lista desplegable. <select name="ciudad">...</select>
<datalist> Opciones sugeridas para un input. <datalist id="opciones">...</datalist>
<fieldset> Agrupa campos. <fieldset>...</fieldset>
<legend> Título de un fieldset. <legend>Datos personales</legend>
<button> Botón. <button type="submit">Enviar</button>

Ejemplo:

<form action="RegistroServlet" method="post">
  <label for="nombre">Nombre:</label>
  <input type="text" id="nombre" name="nombre">

  <input type="hidden" name="accion" value="registro">

  <button type="submit">Enviar</button>
</form>

Campos importantes:

<input type="submit">

envía el formulario.

<input type="button">

no hace nada por sí solo; necesita JavaScript.

<input type="hidden">

envía datos ocultos al usuario, pero visibles/modificables desde el navegador.

1.7. Tablas

Elemento Uso Ejemplo
<table> Tabla. <table>...</table>
<caption> Título de tabla. <caption>Usuarios</caption>
<tr> Fila. <tr>...</tr>
<th> Celda de cabecera. <th>Nombre</th>
<td> Celda normal. <td>Ana</td>

Ejemplo:

<table>
  <caption>Usuarios</caption>
  <tr>
    <th>Nombre</th>
    <th>Edad</th>
  </tr>
  <tr>
    <td>Ana</td>
    <td>24</td>
  </tr>
</table>

1.8. Multimedia

Elemento Uso Ejemplo
<audio> Audio. <audio controls>...</audio>
<video> Video. <video controls>...</video>
<source> Fuente de audio/video. <source src="audio.mp3" type="audio/mpeg">
<track> Subtítulos. <track src="sub.vtt" kind="subtitles">
<canvas> Área para dibujar con JavaScript. <canvas id="lienzo"></canvas>

Ejemplo:

<video controls>
  <source src="video.mp4" type="video/mp4">
  Tu navegador no soporta video.
</video>

2. CSS

CSS sirve para definir el aspecto visual de los elementos HTML.

2.1. Selectores básicos

Selector Uso Ejemplo
p Selecciona etiquetas <p>. p { color: red; }
.clase Selecciona elementos con clase. .caja { border: 1px solid; }
#id Selecciona elemento con id. #menu { background: black; }
p.clase1.clase2 <p> con ambas clases. p.activo.rojo { color: red; }
a[href*="usc"] Atributo que contiene texto. a[href*="usc"] { color: blue; }

Importante:

p.clase1.clase2

no exige que tenga solo esas dos clases. Exige que tenga al menos esas dos.

2.2. Texto y fuentes

Propiedad Uso Ejemplo
color Color del texto. color: red;
font-family Fuente. font-family: Arial, sans-serif;
font-size Tamaño. font-size: 20px;
font-style Cursiva. font-style: italic;
font-weight Grosor. font-weight: bold;
line-height Altura de línea. line-height: 1.5;
text-align Alineación. text-align: center;
text-decoration Subrayado, tachado. text-decoration: underline;
text-transform Mayúsculas/minúsculas. text-transform: uppercase;

Ejemplo:

h1 {
  font-family: Georgia, serif;
  font-size: 32px;
  text-align: center;
}

2.3. Modelo de caja

Propiedad Uso Ejemplo
width Ancho. width: 200px;
height Alto. height: 100px;
margin Espacio exterior. margin: 20px;
padding Espacio interior. padding: 10px;
border Borde. border: 2px solid black;
border-radius Bordes redondeados. border-radius: 8px;
box-sizing Cómo se calcula el tamaño. box-sizing: border-box;
box-shadow Sombra. box-shadow: 0 4px 8px gray;

Ejemplo:

.caja {
  width: 200px;
  padding: 20px;
  border: 4px solid black;
  box-sizing: border-box;
}

box-sizing: border-box hace que el ancho incluya padding y borde.

2.4. Fondos

Propiedad Uso Ejemplo
background Fondo abreviado. background: red;
background-color Color de fondo. background-color: yellow;
background-image Imagen de fondo. background-image: url("fondo.jpg");
background-position Posición. background-position: center;
background-repeat Repetición. background-repeat: no-repeat;

Ejemplo:

body {
  background-color: #f5f5f5;
}

2.5. Display y flujo

Propiedad/valor Uso Ejemplo
display: block Elemento ocupa línea completa. display: block;
display: inline Elemento fluye en línea. display: inline;
display: inline-block En línea, pero permite ancho/alto. display: inline-block;
display: flex Activa flexbox. display: flex;
display: grid Activa grid. display: grid;

Ejemplo:

.contenedor {
  display: flex;
}

2.6. Float y clear

Propiedad Uso Ejemplo
float Hace flotar a izquierda/derecha. float: left;
clear Evita colocarse junto a flotantes. clear: both;

Ejemplo:

img {
  float: left;
  margin-right: 10px;
}

h2 {
  clear: both;
}

clear: both significa que el elemento baja por debajo de floats anteriores.

2.7. Position

Valor Uso
static Valor normal. No acepta top, left, etc.
relative Se mueve respecto a su posición original.
absolute Sale del flujo y se posiciona respecto al ancestro posicionado más cercano.
fixed Se posiciona respecto a la ventana.
sticky Mezcla relative y fixed según scroll.

Ejemplo:

.contenedor {
  position: relative;
}

.hijo {
  position: absolute;
  top: 0;
  right: 0;
}

Importante:

right: 200px;

con position: relative mueve el elemento hacia la izquierda, no hacia la derecha.

2.8. Flexbox

Propiedad Uso
display: flex Activa flexbox.
flex-direction Dirección: fila o columna.
flex-wrap Permite saltar línea.
flex-flow Abreviatura de direction + wrap.
justify-content Alinea en eje principal.
align-items Alinea en eje cruzado.
align-content Alinea varias líneas.

Ejemplo:

.contenedor {
  display: flex;
  justify-content: center;
  align-items: center;
}

Chuleta:

justify-content → eje principal
align-items     → eje cruzado

2.9. Grid

Propiedad Uso
display: grid Activa grid.
grid-template-columns Define columnas.
grid-template-rows Define filas.
grid-template-areas Define áreas.
grid-area Asigna un elemento a un área.
grid-column Posición en columnas.
grid-row Posición en filas.
gap / grid-gap Separación entre celdas.

Ejemplo:

.layout {
  display: grid;
  grid-template-columns: 1fr 3fr;
  grid-template-areas:
    "header header"
    "aside main"
    "footer footer";
}

header {
  grid-area: header;
}

3. JavaScript DOM

JavaScript permite interactuar con el DOM, crear elementos, modificar texto, estilos y eventos.

3.1. Selección de elementos

Método Qué devuelve Ejemplo
getElementById() Un elemento. document.getElementById("caja")
getElementsByClassName() HTMLCollection. document.getElementsByClassName("item")
getElementsByTagName() HTMLCollection. document.getElementsByTagName("p")
getElementsByName() NodeList. document.getElementsByName("usuario")
querySelector() Primer elemento que coincide. document.querySelector(".caja")
querySelectorAll() NodeList con todos. document.querySelectorAll("p")

Ejemplo:

const titulo = document.querySelector("h1");
titulo.textContent = "Hola";

Confuso:

querySelectorAll("p")

devuelve una NodeList, pero solo con los <p> encontrados. No mete nodos texto.

elemento.childNodes

sí puede incluir nodos texto, comentarios y saltos de línea.

3.2. Crear, añadir y borrar nodos

Método Uso Ejemplo
createElement() Crea un elemento. document.createElement("p")
createTextNode() Crea nodo de texto. document.createTextNode("Hola")
appendChild() Añade un nodo hijo. padre.appendChild(hijo)
removeChild() Elimina un hijo. padre.removeChild(hijo)

Ejemplo:

const p = document.createElement("p");
p.textContent = "ETSE USC";

const caja = document.getElementById("miCaja");
caja.appendChild(p);

Borrar:

const p = document.querySelector("#miCaja p");

if (p !== null) {
  p.parentNode.removeChild(p);
}

3.3. Contenido HTML y texto

Propiedad Uso Ejemplo
textContent Texto plano. p.textContent = "Hola";
innerHTML HTML interno. div.innerHTML = "<b>Hola</b>";
nodeValue Valor de un nodo. texto.nodeValue

Diferencia:

elemento.textContent = "<b>Hola</b>";

muestra literalmente <b>Hola</b>.

elemento.innerHTML = "<b>Hola</b>";

crea negrita real.

3.4. Atributos

Método/propiedad Uso Ejemplo
getAttribute() Lee atributo. a.getAttribute("href")
setAttribute() Cambia atributo. img.setAttribute("src", "foto.jpg")
removeAttribute() Elimina atributo. input.removeAttribute("disabled")
hasAttribute() Comprueba si existe. el.hasAttribute("id")
getAttributeNode() Devuelve nodo atributo. el.getAttributeNode("class")
attributes Lista de atributos. el.attributes

Ejemplo:

const enlace = document.querySelector("a");

if (enlace.hasAttribute("href")) {
  console.log(enlace.getAttribute("href"));
}

Confuso:

elemento.attributes

devuelve un NamedNodeMap, no un array normal.

3.5. Nodos y navegación DOM

Propiedad Uso
childNodes Hijos incluyendo texto y comentarios.
children Solo elementos hijos.
firstChild Primer nodo hijo.
firstElementChild Primer elemento hijo.
lastChild Último nodo hijo.
parentNode Padre.
nextSibling Siguiente nodo hermano.
previousSibling Nodo hermano anterior.
nodeName Nombre del nodo.
nodeType Tipo de nodo.

Ejemplo:

const lista = document.querySelector("ul");

console.log(lista.children);      // solo li
console.log(lista.childNodes);    // puede incluir textos/saltos de línea

Tipos frecuentes de nodeType:

1 → nodo elemento
2 → nodo atributo
3 → nodo texto

3.6. Estilos desde JavaScript

Propiedad/método Uso Ejemplo
style Modifica estilos inline. el.style.color = "red"
getComputedStyle() Lee estilo final calculado. getComputedStyle(el)
getPropertyValue() Lee propiedad CSS. estilos.getPropertyValue("background-color")

Ejemplo:

const caja = document.querySelector(".caja");

caja.style.backgroundColor = "red";

const estilos = window.getComputedStyle(caja);
console.log(estilos.getPropertyValue("background-color"));

Importante:

getComputedStyle()

sirve para leer, no para modificar.

elemento.style

sirve para modificar estilos inline.

3.7. Eventos

Método/propiedad Uso Ejemplo
addEventListener() Escucha eventos. btn.addEventListener("click", f)
e.type Tipo de evento. "click"
e.target Elemento donde ocurrió. e.target
e.preventDefault() Cancela acción por defecto. Formulario no se envía.
this Elemento que ejecuta el listener. this.style.color = "red"

Ejemplo:

const boton = document.querySelector("button");

boton.addEventListener("click", function(e) {
  console.log(e.type);
  console.log(e.target);
});

Bubbling y capturing:

elemento.addEventListener("click", funcion, false);

bubbling, por defecto.

elemento.addEventListener("click", funcion, true);

capturing.

3.8. Funciones y argumentos

Elemento Uso Ejemplo
function() Función tradicional. function saludar() {}
Arrow function Función compacta. const f = () => {}
arguments Lista de argumentos en función tradicional. arguments[0]
arguments.length Número de argumentos. arguments.length

Ejemplo:

function sumar() {
  console.log(arguments.length);
}

sumar(1, 2, 3);

Arrow function no tiene su propio arguments.

3.9. Conversión de tipos

Método Uso Ejemplo
parseInt() Convierte a entero. parseInt("12")
parseFloat() Convierte a decimal. parseFloat("12.5")
toString() Convierte a texto. (123).toString()

Ejemplo:

const n = parseFloat("4.5");
console.log(n + 1);

4. Expresiones regulares

Sirven para buscar patrones en texto.

4.1. Métodos principales

Método Uso Ejemplo
test() Devuelve true o false. /a/.test("casa")
exec() Devuelve coincidencia detallada. /a/.exec("casa")
match() Busca coincidencias desde string. "casa".match(/a/g)
matchAll() Todas las coincidencias con grupos. "Ana:20".matchAll(/(\w+):(\d+)/g)
replace() Reemplaza primera o según regex. "hola".replace("h","H")
replaceAll() Reemplaza todas. "aaa".replaceAll("a","b")
search() Devuelve posición. "hola".search(/o/)
split() Divide texto. "a,b".split(",")

Ejemplo:

const regex = /^[\w.-]+@[\w.-]+\.[a-zA-Z]{2,}$/;

console.log(regex.test("a@b.com"));

4.2. Flags

Flag Nombre Uso
g global Busca todas las coincidencias.
i ignoreCase Ignora mayúsculas/minúsculas.
m multiline ^ y $ funcionan por líneas.

Ejemplo:

const texto = "Hola hola";

console.log(texto.match(/hola/gi));

4.3. match() vs matchAll()

"Hola mundo".match(/(Hola) mundo/);

devuelve:

["Hola mundo", "Hola"]

porque no hay g.

Con g:

"Hola mundo Hola tierra".match(/(Hola) \w+/g);

devuelve:

["Hola mundo", "Hola tierra"]

sin grupos.

Con matchAll():

const r = "Hola mundo Hola tierra".matchAll(/(Hola) \w+/g);

puedes obtener todas las coincidencias y sus grupos.

5. jQuery

jQuery simplifica selección, eventos, estilos, animaciones y DOM.

5.1. Selección y objeto jQuery

Elemento Uso Ejemplo
$() Selecciona o crea elementos. $("p")
$(this) Elemento actual como objeto jQuery. $(this).css("color","red")
.ready() Ejecuta al cargar DOM. $(document).ready(function(){})

Ejemplo:

$(document).ready(function() {
  $("p").text("Hola");
});

5.2. Contenido y valores

Método Uso Ejemplo
.text() Lee/cambia texto. $("p").text("Hola")
.html() Lee/cambia HTML. $("div").html("<b>Hola</b>")
.val() Valor de input. $("input").val()

Ejemplo:

const valor = $("#nombre").val();

5.3. Estilos y clases

Método Uso Ejemplo
.css() Lee/cambia CSS. $("p").css("color","red")
.addClass() Añade clase. $("p").addClass("activo")
.removeClass() Quita clase. $("p").removeClass("activo")
.toggleClass() Alterna clase. $("p").toggleClass("activo")
.attr() Lee/cambia atributo. $("img").attr("src","a.png")
.removeAttr() Elimina atributo. $("input").removeAttr("disabled")

Ejemplo:

$("div").css({
  backgroundColor: "red",
  width: "100px"
});

5.4. DOM

Método Uso Ejemplo
.append() Añade al final. $("ul").append("<li>Nuevo</li>")
.prepend() Añade al principio. $("ul").prepend("<li>Primero</li>")
.after() Inserta después. $("p").after("<hr>")
.before() Inserta antes. $("p").before("<hr>")
.remove() Elimina elemento. $("p").remove()
.empty() Vacía contenido. $("div").empty()
.clone() Clona elemento. $("p").clone()
.unwrap() Quita padre. $("span").unwrap()

Ejemplo:

$("#miCaja").append("<p>ETSE USC</p>");

5.5. Recorrido DOM

Método Uso
.parent() Padre directo.
.parents() Todos los ancestros.
.children() Hijos directos.
.find() Descendientes que coinciden.
.closest() Ancestro más cercano que coincide.
.siblings() Hermanos.
.next() Siguiente hermano.
.prev() Hermano anterior.
.eq() Elemento por índice.
.filter() Filtra colección.
.not() Excluye.

Ejemplo:

$("ul").find("li").eq(0).css("color", "red");

5.6. Eventos jQuery

Método Uso Ejemplo
.on() Asigna eventos. $("p").on("click", f)
.preventDefault() Cancela acción. e.preventDefault()
.stopPropagation() Para propagación. e.stopPropagation()

Ejemplo con varios eventos:

$("h2").on("click mouseover", function(e) {
  console.log(e.type);
});

En jQuery puedes poner varios eventos separados por espacios.

5.7. Animaciones y efectos

Método Uso
.hide() Oculta.
.show() Muestra.
.toggle() Alterna visible/oculto.
.fadeIn() Aparece con fundido.
.fadeOut() Desaparece con fundido.
.fadeToggle() Alterna fundido.
.slideDown() Despliega.
.slideUp() Pliega.
.slideToggle() Alterna.
.animate() Animación personalizada.
.delay() Retraso.
.stop() Para animaciones.

Ejemplo:

$("#caja").fadeOut(1000);

7. Servlets

Un servlet es una clase Java que responde a peticiones HTTP.

7.1. Clases y objetos principales

Elemento Uso
HttpServlet Clase base de los servlets.
HttpServletRequest Petición recibida.
HttpServletResponse Respuesta enviada.
HttpSession Sesión del usuario.
Cookie Cookie HTTP.
RequestDispatcher Hace forward o include.
ServletContext Contexto global de la app.

Ejemplo:

public class LoginServlet extends HttpServlet {
    @Override
    protected void doPost(HttpServletRequest request, HttpServletResponse response)
            throws ServletException, IOException {
    }
}

7.2. Métodos HTTP

Método Uso
doGet() Peticiones GET.
doPost() Peticiones POST.

Ejemplo:

protected void doPost(HttpServletRequest request, HttpServletResponse response)
        throws ServletException, IOException {

    String usuario = request.getParameter("usuario");
}

7.3. Request

Método Uso Ejemplo
getParameter() Lee dato de formulario/URL. request.getParameter("nombre")
setAttribute() Guarda dato en request. request.setAttribute("msg","OK")
getAttribute() Lee atributo. request.getAttribute("msg")
getCookies() Lee cookies. request.getCookies()
getSession() Obtiene sesión. request.getSession()

Ejemplo:

String nombre = request.getParameter("nombre");
request.setAttribute("nombre", nombre);

7.4. Response

Método Uso
sendRedirect() Redirige y cambia URL.
sendError() Envía error HTTP.
addCookie() Añade cookie.
setContentType() Tipo de respuesta.

Ejemplo:

response.sendRedirect(request.getContextPath() + "/home.jsp");

7.5. Forward, include y redirect

Método Cambia URL Misma request Uso
forward() No Sí Servlet pasa a JSP.
include() No Sí Incluir otro recurso y volver.
sendRedirect() Sí No Nueva petición del navegador.

Ejemplo:

RequestDispatcher rd = request.getRequestDispatcher("/vista.jsp");
rd.forward(request, response);

7.6. Sesión y cookies

Crear sesión:

HttpSession session = request.getSession();
session.setAttribute("usuario", usuario);

Leer sesión:

Usuario u = (Usuario) session.getAttribute("usuario");

Crear cookie:

Cookie c = new Cookie("tema", "oscuro");
c.setMaxAge(60 * 60 * 24);
response.addCookie(c);

Leer cookies:

Cookie[] cookies = request.getCookies();

7.7. web.xml

Elementos comunes:

Elemento Uso
<web-app> Raíz del descriptor.
<servlet> Declara servlet.
<servlet-name> Nombre lógico.
<servlet-class> Clase Java del servlet.
<servlet-mapping> Mapeo URL.
<url-pattern> Ruta del servlet.
<welcome-file-list> Página inicial.
<welcome-file> Archivo de bienvenida.
<context-param> Parámetro global.
<init-param> Parámetro de servlet.
<session-config> Configuración sesión.
<session-timeout> Minutos de inactividad.
<error-page> Página de error.
<error-code> Código HTTP.
<location> Página destino.

Ejemplo:

<servlet>
  <servlet-name>Login</servlet-name>
  <servlet-class>daw.LoginServlet</servlet-class>
</servlet>

<servlet-mapping>
  <servlet-name>Login</servlet-name>
  <url-pattern>/login</url-pattern>
</servlet-mapping>

8. JSP

JSP permite mezclar HTML con contenido dinámico generado en servidor.

8.1. Directivas JSP

Directiva Uso Ejemplo
<%@ page %> Configura la página. <%@ page contentType="text/html; charset=UTF-8" %>
<%@ taglib %> Declara librerías, como JSTL. <%@ taglib prefix="c" uri="..." %>
<%@ include %> Incluye archivo en tiempo de traducción. <%@ include file="header.jsp" %>

Ejemplo:

<%@ page contentType="text/html; charset=UTF-8" %>
<%@ page import="daw.Usuario" %>

8.2. Scriptlets y sintaxis clásica

Sintaxis Nombre Uso
<% ... %> Scriptlet Código Java.
<%= ... %> Expresión Imprime valor.
<%! ... %> Declaración Declara método o atributo.

Ejemplo scriptlet:

<%
String nombre = request.getParameter("nombre");
%>

<p>Nombre: <%= nombre %></p>

Declaración:

<%!
public String saludar(String nombre) {
    return "Hola " + nombre;
}
%>

<p><%= saludar("Ana") %></p>

Hoy se recomienda evitar scriptlets si se puede, pero en exámenes suelen pedirlos.

8.3. Acciones JSP

Acción Uso
<jsp:include page=""> Incluye otra JSP en ejecución.
<jsp:forward page=""> Pasa control a otra JSP/servlet.
<jsp:useBean> Crea o recupera bean.
<jsp:setProperty> Asigna propiedad.
<jsp:getProperty> Imprime propiedad.

Ejemplo bean:

<jsp:useBean id="usuario" class="daw.Usuario" scope="request" />
<jsp:setProperty name="usuario" property="nombre" value="Ana" />

<p>
  <jsp:getProperty name="usuario" property="nombre" />
</p>

Con formulario:

<jsp:useBean id="usuario" class="daw.Usuario" scope="request" />
<jsp:setProperty name="usuario" property="*" />

Esto rellena propiedades si los name del formulario coinciden con los setters.

8.4. Objetos implícitos JSP clásicos

Objeto Uso
request Petición HTTP.
response Respuesta HTTP.
session Sesión del usuario.
application Contexto global.
out Escribir salida.
pageContext Contexto de página.
config Configuración del servlet/JSP.
page La página actual.
exception Excepción, solo en páginas de error.

Ejemplo:

<%
String nombre = request.getParameter("nombre");
session.setAttribute("usuario", nombre);
%>

9. EL

EL significa Expression Language. Sirve para acceder a datos de forma limpia con ${...}.

9.1. Acceso básico

Servlet:

request.setAttribute("usuario", usuario);

JSP:

<p>${usuario.nombre}</p>

Eso llama internamente a:

usuario.getNombre()

9.2. Objetos implícitos comunes de EL

Objeto Uso Ejemplo
pageScope Atributos de página. ${pageScope.dato}
requestScope Atributos de request. ${requestScope.usuario.nombre}
sessionScope Atributos de sesión. ${sessionScope.usuario.nombre}
applicationScope Atributos globales. ${applicationScope.contador}
param Parámetros simples. ${param.nombre}
paramValues Parámetros múltiples. ${paramValues.aficion[0]}
header Cabeceras HTTP. ${header["User-Agent"]}
headerValues Cabeceras múltiples. ${headerValues.accept[0]}
cookie Cookies. ${cookie.userID.value}
initParam Parámetros de contexto. ${initParam.modo}
pageContext Contexto JSP. ${pageContext.request.contextPath}

Ejemplos:

${param.nombre}

lee un parámetro de formulario o URL.

${requestScope.usuario.nombre}

lee un atributo de request.

${sessionScope.usuario.nombre}

lee un atributo de sesión.

${cookie.tema.value}

lee una cookie.

${pageContext.request.contextPath}

obtiene la ruta base de la aplicación.

9.3. Scopes

Scope Duración Ejemplo
pageScope Solo JSP actual. Variable local.
requestScope Una petición. Datos de servlet a JSP.
sessionScope Varias peticiones del usuario. Usuario logueado.
applicationScope Toda la aplicación. Contador global.

Si escribes:

${usuario}

EL busca en este orden:

pageScope → requestScope → sessionScope → applicationScope

9.4. HashMap en EL

Si tienes:

HashMap<String, String> h = new HashMap<>();
h.put("nombre", "Ana");
request.setAttribute("datos", h);

Puedes hacer:

${datos.nombre}

o:

${datos["nombre"]}

Si la clave tiene espacios o caracteres raros, mejor corchetes:

${datos["nombre completo"]}

10. JSTL

JSTL permite usar etiquetas en JSP para condiciones, bucles y salida.

Primero se declara:

<%@ taglib prefix="c" uri="http://java.sun.com/jsp/jstl/core" %>

o en Jakarta:

<%@ taglib prefix="c" uri="jakarta.tags.core" %>

10.1. Salida y variables

Etiqueta Uso Ejemplo
<c:out> Imprime valor escapado. <c:out value="${usuario.nombre}" />
<c:set> Crea/asigna variable. <c:set var="x" value="10" />

Ejemplo:

<c:set var="saludo" value="Hola" />
<p><c:out value="${saludo}" /></p>

10.2. Condicional simple

<c:if test="${edad >= 18}">
  <p>Mayor de edad</p>
</c:if>

10.3. Condicional múltiple

<c:choose>
  <c:when test="${nota >= 9}">
    <p>Sobresaliente</p>
  </c:when>

  <c:when test="${nota >= 5}">
    <p>Aprobado</p>
  </c:when>

  <c:otherwise>
    <p>Suspenso</p>
  </c:otherwise>
</c:choose>

Equivale a:

if (...) {
} else if (...) {
} else {
}

10.4. Bucles

Bucle numérico:

<c:forEach var="i" begin="1" end="5">
  <p>${i}</p>
</c:forEach>

Bucle sobre lista:

<c:forEach var="usuario" items="${usuarios}">
  <p>${usuario.nombre}</p>
</c:forEach>

Con HashMap:

<c:forEach var="entrada" items="${datos}">
  <p>${entrada.key}: ${entrada.value}</p>
</c:forEach>

11. Java básico para Servlets/JSP

11.1. List

List<String> lista = new ArrayList<>();
lista.add("Ana");
lista.add("Luis");

String primero = lista.get(0);

Uso típico: lista ordenada de elementos.

11.2. ArrayList

ArrayList<Usuario> usuarios = new ArrayList<>();
usuarios.add(usuario);

Permite repetidos.

11.3. Vector

Vector<String> v = new Vector<>();
v.add("A");
v.get(0);

Parecido a ArrayList, pero sincronizado. Es más antiguo.

11.4. HashMap

HashMap<String, Usuario> h = new HashMap<>();

h.put("u1", usuario);
Usuario u = h.get("u1");

Usa pares clave-valor.

Importante:

h.put("u1", usuario1);
h.put("u1", usuario2);

no crea duplicado. Sustituye el valor anterior.
