5. Explica cuál es el cometido de CSS y por qué se introdujo por el W3C. ¿Cómo es la sintaxis de CSS? Nombra sus componentes y pon un ejemplo.

CSS significa Cascading Style Sheets y se introdujo en HTML 4.0 y fue propuesto por W3C para separar contenidos y formato de una web. Su cometido principal es definir el aspecto de los elementos HTML: colores, tamaños, márgenes, bordes, fuentes, distribución en pantalla, posicionamiento, etc.

CSS tiene un selector y un conjunto de reglas/declaraciones. El selector → determina qué elementos serán afectados. La declaración → uno o más pares propiedad/valor separados por ;.

div p {
  color: lime;
}

7. Explica los dos grandes grupos de etiquetas que existen en HTML.

Existen 2 tipos de etiquetas:

  • Etiquetas de bloque
  • Etiquetas de línea

🔹 Etiquetas de bloque

  • Ocupan toda la línea
  • Provocan salto de línea antes y después
  • Ej: h1, p, listas

🔹 Etiquetas de línea

  • No ocupan toda la línea
  • No provocan salto de línea
  • Se adaptan al contenido
  • Ej: a, img, strong

11. ¿Qué significa la etiqueta <meta name="robots" content="noindex, nofollow">?

Directiva para los robots de los motores de búsqueda e indica que la página no debe ser indexada ni mostrada en los resultados de búsqueda (noindex) y que, además, no deben seguirse los enlaces que contiene esa página (nofollow). En conjunto, sirve para evitar que esa página aparezca en buscadores y para impedir que los rastreadores continúen navegando a través de sus enlaces.

13. ¿Para qué se utiliza @import?

@import sirve para importar otro archivo CSS externo y aplicar sus estilos al documento actual.

Ejemplos dados:

@import url("estilos.css");

O:

@import "estilos.css";

14. ¿Qué hace la propiedad box-sizing y qué valores puede tomar?

La propiedad box-sizing indica cómo se calcula el tamaño total de una caja en CSS.

  • content-box: width y height solo incluyen el contenido. El padding y el border se suman aparte.
  • border-box: width y height incluyen contenido, padding y border.

15. ¿De qué librería es esta regla y cómo afecta a la renderización?

<p class="col-sm-8">

La librería/framework es Bootstrap. Usa un sistema responsivo de 12 columnas.

La clase col-sm-8 indica que, en pantallas de tamaño small (sm) o superior, ese elemento ocupará 8 columnas de las 12 disponibles. Es decir, ocupará aproximadamente dos tercios del ancho de la fila.

En pantallas más pequeñas que sm, si no se especifica otra clase, el elemento suele colocarse ocupando todo el ancho disponible, apilándose con otros elementos.

17. Define aplicación web.

Una aplicación web es un conjunto de páginas web generadas en respuesta a peticiones del usuario, típicamente mediante formularios, y necesita tecnologías de front-end y back-end.

También aparece una respuesta de examen: software que se ejecuta en un navegador web y ofrece funcionalidades similares a una aplicación de escritorio, accediéndose por internet sin instalación local.

18. Definición de servlet.

Un servlet es un programa escrito en Java que se ejecuta en el contenedor web de un servidor de aplicaciones y es invocado por un cliente mediante HTTP.

19. Definición de JSP: siglas y qué son.

JSP significa Java Server Pages. Son páginas HTML con líneas de código adicional que se ejecutan en el servidor para generar contenido dinámico. Se traducen automáticamente a servlets.

20. Definición de JavaBean.

Un JavaBean es una clase Java que mantiene datos llamados propiedades, cuyos valores se recuperan/asignan mediante getters y setters.

Debe tener:

  • constructor sin argumentos,
  • getters/setters para atributos privados,
  • implementación de Serializable.

21. ¿Qué significa que una etiqueta sea de línea en HTML?

Una etiqueta de línea, o inline, no inicia una nueva línea de texto. Se coloca dentro de una línea existente y no crea salto de línea adicional.

Ejemplos indicados:

  • <span>
  • <strong>
  • <a>

22. ¿Qué es W3C? ¿Quién lo creó y para qué?

El W3C, World Wide Web Consortium, es una organización internacional que establece estándares y pautas para el desarrollo web.

Fue creado por Tim Berners-Lee en 1994 para promover la interoperabilidad y el crecimiento ordenado de la World Wide Web.

26. Explica el funcionamiento de addEventListener. ¿Cuál es el significado de los parámetros de addEventListener?

addEventListener sirve para asociar un evento a un elemento HTML. Permite detectar y responder a acciones del usuario como:

  • click
  • mouseover
  • keydown
  • submit

Sintaxis:

element.addEventListener(event, callback, useCapture);

Parámetros:

  • event: cadena con el tipo de evento.
  • callback: función que se ejecuta cuando ocurre el evento.
  • useCapture: booleano opcional que indica si se usa captura en lugar de bubbling.

30. ¿Qué papel juegan HttpServletRequest y HttpServletResponse en un servlet?

HttpServletRequest representa la solicitud HTTP recibida por el servidor e incluye parámetros, cabeceras y cuerpo de la solicitud.

HttpServletResponse representa la respuesta enviada al cliente y permite configurar cabeceras, escribir el cuerpo de la respuesta o redirigir.

37. Diferencias en renderizado entre display: block, display: inline y display: inline-block.

display: block hace que el elemento ocupe toda la línea disponible y empiece en una línea nueva; permite modificar width, height, márgenes y padding.

display: inline hace que el elemento se coloque en la misma línea que el texto u otros elementos, ocupando solo lo necesario; no permite controlar bien width y height.

display: inline-block combina ambos: se coloca en línea como un inline, pero permite definir width, height, márgenes y padding como un bloque.

38. Diferencias entre <head> y <header>, <foot> y <footer>.

<head> contiene información interna del documento que no se muestra directamente en la página, como el título, metadatos, enlaces a CSS o scripts. <header> es una etiqueta visible del cuerpo de la página y representa una cabecera de contenido, como el encabezado de una web, una sección o un artículo.

La etiqueta <foot> no es una etiqueta HTML estándar; la correcta es <footer>, que representa el pie de página o pie de una sección, normalmente con información como autoría, contacto, copyright o enlaces relacionados.

39. ¿Qué es un lenguaje de marcas? Nombra dos ejemplos.

Un lenguaje de marcas es un lenguaje que utiliza etiquetas para estructurar, describir o dar significado al contenido de un documento. No es un lenguaje de programación, porque no ejecuta instrucciones lógicas, sino que marca partes del texto o de los datos. Dos ejemplos son HTML, usado para estructurar páginas web, y XML, usado para representar y transportar datos estructurados.

41. ¿Qué framework se utiliza en <div class="col-sm-4">? ¿Qué tamaño máximo puede alcanzar esa cifra en Bootstrap? ¿Qué propiedad de CSS usa Bootstrap para ese layout? ¿Para qué sirve el sistema de columnas de Bootstrap?

<div class="col-sm-4">

pertenece al framework Bootstrap.

Bootstrap utiliza un sistema de rejilla responsive basado en 12 columnas, por lo que la cifra máxima habitual es 12. En este caso, col-sm-4 indica que el elemento ocupará 4 columnas de 12 en pantallas de tamaño sm o superior.

Bootstrap usa principalmente Flexbox, es decir, la propiedad CSS:

display: flex;

Este sistema sirve para generar páginas responsivas, adaptando la distribución de los elementos según el tamaño de pantalla. En pantallas sm o superiores se crean columnas; en pantallas más pequeñas, los elementos suelen colocarse unos debajo de otros.

46. ¿Qué dos atributos son los más usados en <div> y en qué se diferencian?

  • class: identifica conjuntos de etiquetas y puede aplicarse a varias etiquetas.

47. ¿Qué son request y response y para qué sirven?

request y response son instancias de HttpServletRequest y HttpServletResponse. Encapsulan la información asociada a la petición y a la respuesta de una conexión HTTP.

Permiten obtener parámetros enviados por formulario y establecer una respuesta.

51. ¿Qué método de intercambio utilizan los formularios y qué implicaciones tiene?

Los formularios usan principalmente GET y POST: GET envía los datos en la URL y se usa para consultas; POST los envía en el cuerpo de la petición y se usa para enviar/modificar datos de forma más segura y con mayor tamaño.

<form action="procesar" method="get">

<form action="procesar" method="post">

70. Definición de JSP, EL y JSTL.

JSP: páginas HTML con código adicional ejecutado en servidor para contenido dinámico.

EL: Expression Language proporciona una sintaxis compacta para manejar JavaBeans, arrays, listas y mapas almacenados como atributos.

JSTL: JavaServer Standard Tag Library amplía la funcionalidad de JavaBeans con etiquetas estándar que permiten eliminar scriptlets de JSP.
