 200 OK

400 parametros invalidos		 GET es seguro e idempotente. Filtros, orden y paginación van en la query. Una lista vacía es 200 y no 404, porque la colección existe.
3 Consultar todas las ofertas de una empresa concreta, incluidas las cerradas. /ofertas GET obtener ofertas cerradas ?empresa={idEmpresa} Accept-Type:application/json 200 OK

400 parametros invalidos		 se reutiliza la misma colección que en la fila 2 en vez de crear una paralela. La alternativa /empresas/{id}/ofertas también es válida, pero entonces tendrías que usar ese estilo en todo y devolver 404 si la empresa no existe. Lo que no puedes hacer es mezclar los dos estilos, que fue tu error del otro día.

Código Nombre Cuándo se usa
1XX Informativos La petición está en proceso
2XX Éxito La petición se ha procesado correctamente
3XX Redirecciones El cliente debe realizar alguna acción adicional para completar la petición
4XX Error del cliente La petición tiene un error y el cliente debe modificarla para que sea válida
5XX Error del servidor Error al procesar la petición en el servidor, aunque la petición fuese correcta. Hay que reducir al máximo que lleguen al cliente
200 OK Éxito genérico. También se usa con una lista vacía cuando la colección existe pero ningún recurso cumple el filtro
201 Created Se ha creado un recurso nuevo
204 No Content Éxito con el cuerpo de la respuesta vacío intencionadamente
400 Bad Request Error genérico del cliente. Mejor usar uno más específico si existe
401 Unauthorized Error de autenticación: no hay credenciales o son incorrectas
403 Forbidden Error de autorización: credenciales correctas pero sin permisos para el recurso u operación
404 Not Found El recurso al que se intenta acceder no existe
406 Not Acceptable El servidor no puede devolver la respuesta en ninguno de los formatos que pide el cliente en Accept
409 Conflict La petición entra en conflicto con el estado actual del recurso
422 Unprocessable Entity La petición está bien formada pero su contenido no es válido o incumple reglas de negocio
429 Too Many Requests El cliente ha enviado demasiadas peticiones en poco tiempo
