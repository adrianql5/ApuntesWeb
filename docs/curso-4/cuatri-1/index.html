2. Conceptos básicos (léelo si eres nuevo)

¿Qué es "CFW" (Custom Firmware)?

Es un sistema modificado que se carga encima del sistema original de Nintendo. En tu caso es Luma3DS. Gracias a él puedes:

  • Instalar juegos y apps que no vienen de la eShop.
  • Usar homebrew (programas caseros).
  • Poner temas personalizados, trucos, mods, etc.

Tipos de archivos que vas a ver

Extensión Qué es Cómo se usa
.cia Juego/app instalable de 3DS (como un .apk en Android) Se instala con FBI → aparece como icono en el menú HOME
.3dsx App homebrew no instalada Se abre desde el Homebrew Launcher (carpeta /3ds/)
.3ds Copia de cartucho de 3DS Mejor convertirla o buscar la versión .cia
.nds Juego de Nintendo DS Se abre con TWiLight Menu++
.gba Juego de Game Boy Advance Con open_agb_firm, mGBA o TWiLight Menu++
.firm "Payload" de arranque (p.ej. GodMode9) Se lanza manteniendo START al encender
.zip (temas) Tema del menú HOME Se aplica con Anemone3DS

Juego base, actualización y DLC

En la 3DS un juego puede tener 3 partes separadas, y cada una es un .cia distinto:

  1. Base (el juego en sí) — siempre primero.
  2. Update (actualización / parche).
  3. DLC (contenido descargable).

👉 Instálalos SIEMPRE en ese orden: Base → Update → DLC.

sysNAND vs emuNAND

Tú usas sysNAND (la memoria interna real, autoboot_emunand = 0). Es lo normal hoy en día; no necesitas emuNAND.

¿Puedo actualizar el sistema de la consola?

Sí. Con boot9strap + Luma3DS las actualizaciones oficiales de Nintendo no quitan el hackeo. Puedes actualizar desde Configuración de la consola → Otras opciones → Actualización de la consola sin miedo.

Qué NO debes borrar jamás

  • boot.firm → sin él, la consola arranca con pantalla negra.
  • Nintendo 3DS/ → aquí están todos tus juegos instalados y partidas (cifrados, solo funcionan en esta consola).
  • 3ds/dspfirm.cdc → sin él, el homebrew no tiene sonido.
  • boot9strap/, gm9/backups/, gm9/out/ → copias de seguridad (mejor tenerlas también en el PC).

Qué SÍ puedes borrar sin miedo

  • Los .cia después de instalarlos (ya están dentro de Nintendo 3DS/).
  • Temas .zip que no uses.
  • 3ds/Anemone3DS/cache/.
  • Carpetas .Spotlight-V100, .fseventsd, System Volume Information (las crean macOS/Windows; no molestan, pero sobran).

4. Las apps que tienes y cómo se usan

4.1 Menú Rosalina (Luma3DS) — L + ↓ + SELECT

Es el "panel de control" del CFW. Funciona en cualquier momento. Opciones más útiles:

Opción Para qué sirve
Cheats... Activar trucos en el juego abierto (ver sección 9)
Take screenshot Hacer captura de pantalla (se guarda en /luma/screenshots/)

New 3DS menu No aplica (tu consola es Old 3DS)

Power options Apagar / reiniciar de forma segura
System configuration Activar/desactivar Wi-Fi, LED, etc.

4.2 Menú de configuración de Luma3DS — mantener SELECT al encender

Enciende la consola manteniendo SELECT y aparece el menú de configuración de Luma. Opciones relevantes:

  • Enable game patching → actívalo si quieres usar mods de juegos (LayeredFS) o parches de idioma. Ahora mismo lo tienes desactivado (enable_game_patching = 0).
  • Show NAND or user string in System Settings → muestra "Sys" en Configuración (lo tienes activado).
  • Pulsa START para guardar y salir.

4.3 GodMode9 — mantener START al encender

Gestor de archivos de nivel "dios": puede ver y modificar TODO (NAND, SD, cartuchos). ⚠️ Es potente y peligroso: si no sabes lo que haces, solo úsalo para leer o hacer copias.

Usos típicos:

  • Hacer copia de la NAND: HOME → Scripts... → GM9Megascript → Backup Options → SysNAND Backup.
  • Volcar tus cartuchos a .cia: con el cartucho puesto, entra en [C:] GAMECART → pulsa sobre el .3ds → NCSD image options → Build CIA from file. El .cia aparece en gm9/out/ y lo instalas con FBI.
  • Volcar juegos instalados: HOME → Title manager.
  • Para salir: START → Reboot o Poweroff.

4.4 Homebrew Launcher (boot.3dsx)

Es el "escritorio" donde aparecen todas las apps .3dsx de la carpeta /3ds/.

  • Cómo abrirlo: desde el menú Rosalina → Miscellaneous options → Switch the hb. title to the current app… pero lo más fácil es instalar el "Homebrew Launcher Wrapper" como CIA desde Universal-Updater, así tienes un icono directo en el menú HOME.
  • También se abre lanzando la app Download Play (es la app que Luma "secuestra" por defecto: hbldr_3dsx_titleid = 000400000d921e00).

4.5 FBI — instalador de juegos y explorador de archivos

FBI es la herramienta principal para instalar .cia. Ábrelo desde el Homebrew Launcher (o instálalo como CIA para tener icono).

Menú principal de FBI:

Opción Qué hace

CTR NAND / TWL NAND... Memoria interna. No toques nada aquí
Titles Lista de juegos/apps instalados (para borrar, ver tamaño, etc.)

Instalar un .cia con FBI (método básico)

  1. Abre FBI → SD.
  2. Navega hasta la carpeta donde están tus .cia (por ejemplo /Roms/3ds/ o /cias/).
  3. Para un archivo: selecciónalo con A → Install and delete CIA (lo instala y borra el .cia para liberar espacio) o Install CIA (lo instala y deja el archivo).
  4. Para todos los de la carpeta a la vez: selecciona <current directory> (la primera línea) → Install and delete all CIAs. ⭐ Esto es lo que usarás para instalar muchos juegos de golpe.
  5. Confirma con A y espera. Al acabar, vuelve al menú HOME: aparecerán los juegos (a veces dentro de un "regalo" que hay que abrir).

4.6 faketik

Si instalas un juego y no aparece su icono en el menú HOME, abre faketik desde el Homebrew Launcher. Genera los "tickets" que faltan y el icono aparece. Tarda unos segundos; luego reinicia.

5. Instalar juegos desde la consola (hShop / 3hs)

🌐 Web oficial: https://hshop.erista.me/

hShop es una "tienda" con prácticamente todo el catálogo de 3DS (juegos, actualizaciones, DLC, Virtual Console, DSiWare, temas…). Se puede usar desde la consola o desde el PC.

5.1 Usar la app 3hs en la consola

  1. Abre hShop / 3hs desde el menú HOME.
  2. La primera vez descarga el índice (tarda un poco).
  3. Navega por categorías:
    • Games → juegos de 3DS (busca por región: Europe para tu consola, aunque Luma permite jugar a casi cualquier región).
    • Updates → actualizaciones.
    • DLC → contenido descargable.
    • Virtual Console → NES, SNES, GB, GBC, GBA, Game Gear…
    • DSiWare → juegos DSi.
  4. Selecciona el juego → pulsa A → se descarga e instala directamente.
  5. Puedes poner varios en cola (Queue) y dejar la consola descargando.

5.2 Instalar escaneando un QR (sin descargar al PC)

  1. En el PC abre https://hshop.erista.me/, busca el juego y entra en su ficha.
  2. Pulsa el botón para mostrar el QR.
  3. En la consola: FBI → Remote Install → Scan QR Code y apunta la cámara al QR.
  4. Se descarga e instala.

5.3 ¿Por qué es lento?

El Wi-Fi de la 3DS es 802.11b/g y su procesador es muy lento descifrando: en la práctica se descarga a ~200–600 KB/s. Un juego de 1 GB puede tardar 30–60 minutos. Para muchos juegos, usa el PC 👇

6. ⚡ Instalar MUCHOS juegos rápido desde el PC

Hay varios métodos. De más recomendado a más avanzado:

Método Velocidad Dificultad Ideal para
6.1 Descargar en el PC + copiar a la SD + FBI ⭐⭐⭐⭐ Fácil Lo normal. Recomendado
6.2 Envío por Wi-Fi local (Boop / servefiles) ⭐⭐ Fácil Sin sacar la SD, pocos juegos
6.3 FTP con ftpd ⭐⭐ Media Pasar archivos sin sacar la SD
6.4 custom-install (instala directo a la SD desde el PC) ⭐⭐⭐⭐⭐ Avanzada Cargas masivas de muchos GB

6.1 Método recomendado: descargar en el PC y copiar a la SD

Paso 1 — Descargar los .cia en el PC

  1. Abre https://hshop.erista.me/ en el navegador del PC.
  2. Busca el juego (barra de búsqueda arriba) o navega por Games → región (Europe / North America / Japan…).
  3. Entra en la ficha del juego y pulsa Download. Se descarga un archivo .cia.
  4. Si quieres la actualización y/o DLC, búscalos en las categorías Updates y DLC (mismo nombre del juego) y descárgalos también.
  5. Repite con todos los juegos que quieras.

💡 Consejos para descargar muchos a la vez

  • Abre varias pestañas y lanza varias descargas en paralelo (no te pases: hShop tiene límites y es un servicio gratuito mantenido por voluntarios; no uses scripts que lo saturen).
  • Si una descarga se corta, usa un gestor de descargas que permita reanudar (el propio del navegador suele bastar; también Free Download Manager o JDownloader).
  • Organiza en una carpeta del PC, por ejemplo Descargas/3DS_para_instalar/.
  • Revisa que el tamaño cabe: tu SD tiene 15 GB con ~13 GB libres. Los juegos de 3DS suelen ocupar entre 100 MB y 4 GB. ¡Y necesitas espacio para el .cia y para el juego instalado a la vez durante la instalación!

Paso 2 — Copiar a la SD

  1. Apaga la consola (o usa Rosalina → Power options → Power off) y saca la SD.
  2. Métela en el PC (lector de tarjetas).
  3. Crea una carpeta en la raíz de la SD, por ejemplo /cias/ (o usa la que ya tienes: /Roms/3ds/).
  4. Copia ahí todos los .cia descargados.
  5. Si usas Mac, antes de expulsar ejecuta en la Terminal (borra los archivos basura ._algo que macOS crea en las tarjetas FAT32 y que a veces dan errores en la 3DS):
    dot_clean -m "/Volumes/NO NAME"
  6. Expulsa la SD correctamente (Finder → botón ⏏ / Windows → "Quitar hardware de forma segura"). Si la sacas sin expulsar puedes corromperla.

Paso 3 — Instalar todo de golpe con FBI

  1. Mete la SD en la consola y enciéndela.
  2. Abre FBI → SD → cias (o Roms → 3ds).
  3. Selecciona <current directory> → Install and delete all CIAs.
  4. Confirma y deja la consola enchufada al cargador mientras instala.
  5. Al terminar, vuelve al HOME. Si algún icono no aparece → abre faketik y reinicia.

⚠️ Orden importante: si en la misma carpeta tienes base + update + DLC, FBI los instala por orden alfabético, lo que normalmente funciona. Si una update/DLC da error, instala primero la base sola y luego el resto.

6.2 Enviar por Wi-Fi local desde el PC (Boop / servefiles)

Útil si no quieres sacar la SD. Va por tu red de casa, así que es algo más rápido que descargar de internet, pero sigue limitado por el Wi-Fi de la 3DS.

Con Boop (Windows, fácil):

  1. Descarga Boop: https://github.com/miltoncandelero/Boop/releases
  2. En la consola: FBI → Remote Install → Receive URLs over the network.
  3. Abre Boop en el PC, escribe la IP que muestra la 3DS, arrastra los .cia y pulsa Boop.

Con servefiles (Mac/Linux/Windows, Python):

  1. Descarga servefiles.py de: https://github.com/Steveice10/FBI/tree/master/servefiles
  2. En la consola: FBI → Remote Install → Receive URLs over the network (anota la IP).
  3. En la Terminal del PC:
    python3 servefiles.py 192.168.1.XX /ruta/a/la/carpeta/de/cias

6.3 FTP con ftpd

  1. Instala ftpd desde Universal-Updater.
  2. Ábrelo en la consola; mostrará algo como 192.168.1.XX:5000.
  3. En el PC conéctate con un cliente FTP:
    • FileZilla (Win/Mac/Linux): https://filezilla-project.org/
    • Cyberduck (Mac): https://cyberduck.io/
    • WinSCP (Windows): https://winscp.net/ Servidor: la IP, puerto 5000, sin usuario ni contraseña (modo anónimo).
  4. Copia los .cia a /cias/ y luego instálalos con FBI (paso 3 de 6.1).

6.4 Avanzado: custom-install (el más rápido para cargas enormes)

custom-install instala los .cia directamente en la SD desde el PC, cifrándolos con las claves de tu consola. Así te ahorras la lenta instalación en la 3DS.

Requisitos (todos los puedes sacar de tu propia consola con GodMode9):

  • boot9.bin → ya lo tienes en gm9/out/00010017/ (cópialo al PC).
  • movable.sed → en GodMode9: [1:] SYSNAND CTRNAND → private → movable.sed → copiar a 0:/gm9/out/.
  • Python 3 en el PC.

Pasos:

  1. Descarga: https://github.com/ihaveamac/custom-install
  2. Sigue su README para instalar dependencias (pip install -r requirements.txt). Tiene interfaz gráfica (ci-gui.py).
  3. Indica: boot9.bin, movable.sed, la ruta de la SD y añade los .cia.
  4. Pulsa instalar. Cuando acabe, expulsa la SD.
  5. En la consola abre custom-install-finalize (lo copia automáticamente a la SD) para registrar los juegos. Si algún icono no sale → faketik.

⚠️ boot9.bin, movable.sed, otp.bin y similares son únicos de tu consola. No los compartas con nadie.

7. Juegos de DS, DSi y GBA

7.1 Juegos de DS (.nds) con TWiLight Menu++

Ya tienes TWiLight Menu++ instalado (según Universal-Updater) y nds-bootstrap v2.17.0.

  1. Descarga los .nds en el PC (tienes también DS en otras webs de ROMs; para DSiWare usa la sección DSiWare de hShop).
  2. Copia los .nds a /Roms/nds/ en la SD (puedes hacer subcarpetas).
  3. Abre TWiLight Menu++ desde el menú HOME.
  4. Elige el juego y pulsa A.
  5. Las partidas se guardan solas en /Roms/nds/saves/ (archivos .sav).

Ajustes útiles de TWiLight (botón SELECT o el engranaje en el menú):

  • Tema del menú: estilo DSi, 3DS, R4, Akmenu…
  • Ajustes por juego (pulsa Y sobre un juego): velocidad de CPU (TWL clock), VRAM boost, idioma…
  • Pantalla ancha (widescreen): TWiLight puede jugar algunos juegos en pantalla ancha (tienes el widescreen.pck en extras).
  • Carátulas (boxart): pon imágenes .png en _nds/TWiLightMenu/boxart/ con el nombre del juego o su código. TWiLight tiene opción para descargarlas.
  • Filtros de color: los .lut de _nds/colorLut/ (luz cálida, escala de grises…).

7.2 Juegos y DSiWare (DSi)

  • Juegos DSi exclusivos / DSiWare como archivo → /Roms/dsi/, saves en /Roms/dsi/saves/.
  • DSiWare en .cia (de hShop) → se instalan con FBI como cualquier otro .cia.

7.3 Game Boy Advance (.gba)

Tienes tres opciones:

  1. Virtual Console de hShop (.cia) → se instalan con FBI y quedan como icono. Lo más cómodo.
  2. open_agb_firm (recomendado para .gba sueltos): instálalo con Universal-Updater; los .gba van en /3ds/open_agb_firm/ o donde indique. Rendimiento perfecto (usa el hardware GBA real de la 3DS). Se lanza con START al encender (aparece en el menú de payloads).
  3. mGBA (homebrew) → emulador, permite estados de guardado.

Crea una carpeta /Roms/gba/ para tenerlos ordenados.

7.4 Otras consolas retro

Con RetroArch o emuladores individuales de Universal-Updater puedes jugar NES, SNES, Mega Drive, Game Boy… Crea carpetas /Roms/nes, /Roms/snes, /Roms/gb, etc. TWiLight Menu++ también abre muchas de estas directamente.

8. Temas, insignias y personalización (ThemePlaza)

🌐 Web de temas: https://themeplaza.art/

En ThemePlaza hay miles de temas para el menú HOME, pantallas de arranque (splashes) e insignias (badges).

8.1 Método A — Escanear QR (sin PC)

  1. En el PC o móvil abre https://themeplaza.art/ y busca un tema.
  2. En la ficha del tema verás un código QR.
  3. En la consola abre Anemone3DS → pulsa L o R hasta el modo de cámara/QR (o toca el icono de QR) → apunta al código.
  4. Se descarga a /Themes/. Acepta y listo.

8.2 Método B — Descargar el .zip en el PC

  1. En ThemePlaza pulsa Download → obtienes un .zip.
  2. NO lo descomprimas. Cópialo tal cual a /Themes/ de la SD (ya tienes 6 ahí: MF DOOM, Saramalacara, Screws, efn2, kkk…).
  3. Mismo procedimiento para:
    • Splashes → carpeta /Splashes/
    • Badges (insignias) → carpeta /Badges/ (ya tienes ThemePlaza Badges)

8.3 Aplicar el tema con Anemone3DS

  1. Abre Anemone3DS.
  2. Navega con la cruceta por la lista de temas (verás la vista previa arriba).
  3. Pulsa A → Install (instalar) o Install with music/without BGM según quieras música o no.
  4. Shuffle (aleatorio): marca varios temas con Y y elige Install shuffle → el menú HOME irá alternando entre ellos.
  5. Cierra Anemone y vuelve al menú HOME. Si no ves el tema: mantén pulsado L en el HOME, entra en Cambiar tema y selecciona la ranura de tema personalizado (o reinicia).

8.4 Insignias (badges)

  1. Pon las insignias (.png sueltos o carpetas) en /Badges/.
  2. En Anemone3DS cambia al modo Badges (pulsa R para cambiar de pestaña Themes → Splashes → Badges, según versión).
  3. Instálalas. Aparecerán en el menú HOME como si las hubieras ganado en el Centro de Insignias.
  4. Anemone guarda copia de tus insignias anteriores en 3ds/Anemone3DS/BadgeBackups/.

8.5 Splashes (pantalla de arranque)

Ahora tienes el splash desactivado (splash_position = off). Para activarlo: enciende con SELECT → en el menú de Luma activa el splash → pon el splash con Anemone (pestaña Splashes).

9. Extras útiles: trucos, capturas, partidas guardadas, online

9.1 Trucos (cheats)

  1. Descarga trucos (archivos .txt con nombre = Title ID del juego). Buenas fuentes: base de datos de trucos de Checkpoint o la de https://github.com/JourneyOver/CTGP-7-Cheats / https://github.com/iSharingan/CTRPF-AR-CHEAT-CODES.
  2. Cópialos a /cheats/ en la raíz de la SD (crea la carpeta), p.ej. /cheats/00040000001B5000.txt.
  3. Dentro del juego: L + ↓ + SELECT → Cheats... → activa los que quieras.

9.2 Mods y traducciones (LayeredFS)

  1. Activa Enable game patching (encender con SELECT).
  2. Pon los archivos del mod en /luma/titles/<TitleID>/romfs/... (cada mod explica su ruta).

9.3 Capturas de pantalla

L + ↓ + SELECT → Take screenshot → se guardan en /luma/screenshots/ (sácalas por SD o FTP).

9.4 Copias de partidas guardadas — Checkpoint

  1. Instala Checkpoint desde Universal-Updater.
  2. Ábrelo, selecciona un juego → Backup (crea copia en /3ds/Checkpoint/saves/).
  3. Para restaurar: selecciona la copia → Restore.
  4. Haz esto antes de borrar un juego o de probar trucos.

9.5 Jugar online

La eShop y los servidores oficiales de Nintendo cerraron en 2023/2024. Para volver a jugar online (Mario Kart 7, Pokémon, Smash…), usa Pretendo Network (servidores de la comunidad): https://pretendo.network/

10. Mantenimiento y copias de seguridad

10.1 ⚠️ Haz esto YA: copia de seguridad en el PC

Tienes en la SD una copia de tu NAND (gm9/backups/260805_CJH10327628_sysnand_00.bin, del 5 de agosto de 2026) y archivos esenciales. Si se pierde o rompe la SD, desaparecen. Cópialos a tu PC (y mejor también a la nube/disco externo):

  • gm9/backups/ (todo: NAND + essential_00.exefs)
  • gm9/out/ (otp.bin, boot9.bin, etc.)
  • boot9strap/ (firm0/firm1 backups)
  • luma/backups/

Esa copia de la NAND es lo que te permite resucitar la consola si algún día se brickea.

10.2 Copia de toda la SD

De vez en cuando, copia toda la SD a una carpeta del PC. Así guardas juegos instalados, partidas, temas… Si cambias de SD, basta con copiar todo a la nueva.

10.3 Cambiar a una SD más grande

  1. Copia todo el contenido de la SD actual al PC.
  2. Formatea la nueva en FAT32 (no exFAT):
    • Mac: diskutil eraseDisk FAT32 3DS MBRFormat /dev/diskX (¡comprueba bien el diskX con diskutil list!).
    • Windows: usa GUIFormat (http://ridgecrop.co.uk/index.htm?guiformat.htm) para tarjetas de más de 32 GB, tamaño de clúster 32K.
  3. Copia todo de vuelta. Listo, la consola no notará el cambio.

10.4 Mantener todo actualizado

Abre Universal-Updater de vez en cuando y actualiza Luma3DS, FBI, Anemone3DS, TWiLight Menu++, 3hs…

11. Solución de problemas

Problema Solución
Pantalla negra al encender Falta o está dañado boot.firm en la raíz. Vuelve a copiar el de Luma3DS (https://github.com/LumaTeam/Luma3DS/releases)
Instalé un juego y no aparece el icono Abre faketik y reinicia. Mira también si hay un "regalo" en el HOME
FBI da error al instalar 1) Mira si hay espacio libre en la SD. 2) Borra instalaciones a medias en FBI → Pending Titles. 3) Vuelve a descargar el .cia (puede estar corrupto). 4) Instala primero el juego base y luego update/DLC. 5) El último error queda registrado en luma/errdisp.txt
La 3DS dice "error" y se cuelga (pantalla de excepción de Luma) Pulsa cualquier botón para reiniciar. Anota el código de error para buscarlo
El juego de DS no arranca o va lento Actualiza TWiLight Menu++ y nds-bootstrap. Pulsa Y sobre el juego y prueba otras opciones (CPU, VRAM). Consulta la lista de compatibilidad en la wiki de TWiLight
El tema no se aplica En el HOME: mantén L → ajustes de tema → elige el tema personalizado. Reinicia
El homebrew no tiene sonido Falta 3ds/dspfirm.cdc. Genéralo con DSP1 (Universal-Updater)
Archivos raros ._nombre en la SD (Mac) Ejecuta dot_clean -m "/Volumes/NO NAME" antes de expulsar
SD "dañada" o en solo lectura Comprueba la pestañita de bloqueo del adaptador SD. En Mac: Utilidad de Discos → Primera ayuda
Quiero desactivar el CFW temporalmente No se puede "desactivar" fácil; pero puedes arrancar sin SD (arranca el sistema normal, sin homebrew)
