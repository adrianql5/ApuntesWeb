# plantillas/ — Contenido canónico

Rol: guardián de los formatos de contenido fuente.

- `README-cuatrimestre.md` es el formato canónico del archivo de observaciones que
  vive en la raíz de cada bóveda de teoría (profesorado, dificultad, evaluación,
  consejos, opinión por asignatura).
- La skill `normalizar-readme` migra/crea los README de las bóvedas según esta
  plantilla, preservando siempre el contenido y el tono personal existentes.
- Cambios de formato aquí implican actualizar esa skill y avisar de que los README
  ya migrados quedarán desactualizados.
